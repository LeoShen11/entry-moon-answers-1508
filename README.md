The Moon finally answers back: one line, in the Moon's own weary voice, to four billion years of wishes, howls, and 2 a.m. promises — "Four billion years of wishes, howls, and 2 a.m. promises — and I'm still the only one up here keeping mine." The program validates the line (1–240 characters, a single non-blank line) and writes it to `/output/entry.txt`, then reads it back to prove what landed on disk is exactly the line.

## Run it

```sh
node main.ts
```

It writes the Moon's comeback to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and prints its character and word counts.
